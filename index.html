📱 Cách 1: Lưu nhanh lên Google Drive

Trên máy tính: Tải tệp sao lưu và tự động mở Google Drive để bạn thả file vào.

⚡ Cách 2: Đồng bộ đám mây tự động

Tự động đồng bộ 1 chạm qua Google Drive API riêng tư vào file miu_english_backup.json trên Drive của bạn.

✅ Đã tích hợp sẵn Client ID từ dự án Google Cloud của bạn! Bạn chỉ cần nhấn nút ⬆️ Đẩy lên Drive để đăng nhập tài khoản Google và đồng bộ tự động.

🌐 Hướng Dẫn Tải Lên GitHub Pages

🌟 Lợi ích của GitHub Pages:

1. Miễn phí 100% trọn đời do GitHub (Microsoft) tài trợ máy chủ.
2. Có link web bảo mật https:// riêng để mở trên cả Điện thoại lẫn Máy tính mọi lúc mọi nơi.
3. Dữ liệu tiến độ và từ vựng tự thêm được đồng bộ dễ dàng qua Google Drive hoặc sao lưu JSON.

Bước 1: Tạo kho lưu trữ trên GitHub Đăng nhập github.com/new, đặt tên repository là english-hub (chọn chế độ Public), nhấn Create repository.
Bước 2: Tải thư mục này lên GitHub Mở Terminal hoặc Command Prompt tại thư mục dự án và chạy các lệnh: 
git init
git add .
git commit -m "Deploy Miu Student English"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/english-hub.git
git push -u origin main
(Thay YOUR_USERNAME bằng tên tài khoản GitHub của bạn)
Bước 3: Bật GitHub Pages Vào repository trên web GitHub → Bấm Settings → Chọn Pages (cột bên trái) → Tại phần Branch chọn main và thư mục / (root) → Bấm Save.
Bước 4: Mở trên điện thoại & ghim thành App Sau 1-2 phút, bạn sẽ có link: https://YOUR_USERNAME.github.io/english-hub/. Mở link trên Safari/Chrome trên điện thoại → Bấm "Thêm vào màn hình chính" để sử dụng toàn màn hình như một ứng dụng thật!
